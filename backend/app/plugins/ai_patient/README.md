# AI patient (optional)
Set enabled=true in plugins.toml. Ollama defaults to localhost:11434 and requires a separately installed model. OpenAI and Anthropic need environment keys and their provider-specific model names. Restart, then open Free chat from Encounters. Remote providers charge token-based fees; Ollama uses local compute. No model is bundled and no paid requests occur by default. Transcripts are kept in browser memory and are sent to the selected provider on each turn. Use fictional patient details. Rubric phrase counts are deterministic; corrections come from the model.
